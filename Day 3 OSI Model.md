	Protocol: 
		-set of rules how should communicate.

	tcp-ip:
		-open standard that any vendor could implement.
		-Application Layer (HTTP/HTTPS, TFTP, SMTP, POP3), Transport Layer (PORT NUMBERS, UDP, TCP), Internet Layer (IP ADDRESSES, ROUTERS), Local Network Layer (HOP TO HOP WITHING A LOCAL NETWORK, MACS) and Physical Layer (NIC CARDS).

	Standards: 
		-IEEE (Ethernet, wifi)
		-IETF (TCP,IP,UDP,HTTP,DNS)

	Layered Models:
		-Groups related jobs into layers.
		-Each layer talks to the same layer on other device.

	Encapsulation and decapsulation:
		-each layer adds or remove headers/trailers.

	OSI model:
		-7 Layers.
		-Please do not throw sausage pizza away:
			Please → Physical (1): ones and ceros
			Do → Data Link (2) : macs, switches
			Not → Network (3) : ip addreses
			Throw → Transport (4) : transmit data (tcp, udp)
			Sausage → Session (5) : manages sessions
			Pizza → Presentation (6) : data encrypts occurs
			Away → Application (7) : Human interaction
