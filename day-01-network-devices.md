# Day 1 – Network Devices

Source: Jeremy's IT Lab, Free CCNA, Day 1

## Key terms

**Network:** a group of devices connected so they can share data.

**Nodes:** the devices in a network (PCs, phones, servers, switches, routers, firewalls).

## Clients and servers

**Client:**
- An end device that requests and uses services made available by a server.
- Examples: laptops, phones.

**Server:**
- Provides functions or services for clients.
- Examples: web servers, file servers.

> Client and server are *roles*, not types of hardware. The same device can be a client in one exchange and a server in another.

## Switches

- Forward traffic **within a LAN** (local area network).
- Have many ports, so lots of end devices can connect.
- Do **not** provide connectivity between LANs or over the internet.

## Routers

- Have fewer network interfaces than switches.
- Provide connectivity **between LANs**.
- Send data over the internet.

> Quick way to remember: switches connect devices *inside* a network; routers connect *networks to each other*.

## Firewalls

- Special security devices that **monitor and control** traffic going in and out of the network.
- Use configured **rules** to decide which traffic is allowed and which is blocked.
- Protect the hosts inside the network.
- Can be placed inside or outside the router, or both.
- **Next-generation firewalls (NGFW):** newer firewalls with extra security features.
- **Network firewall:** a hardware device that filters traffic between networks.
- **Host-based firewall:** software running on a single device (for example, Windows Defender Firewall) that filters traffic in and out of that device only.
